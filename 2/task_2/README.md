# Параллельное вычисление определённого интеграла (OpenMP)

## Описание
Данная программа реализует параллельное численное вычисление определённого интеграла функции с использованием технологии **OpenMP**.

Интеграл вычисляется методом **средних прямоугольников**. Область интегрирования разбивается на большое количество шагов, которые распределяются между потоками для ускорения вычислений на многопроцессорных системах.

Программа также выполняет **измерение времени выполнения** для различных количеств потоков, что позволяет оценить эффективность параллельного алгоритма.

## Функциональность

- параллельное вычисление определённого интеграла
- распределение вычислений между потоками
- использование **OpenMP** для распараллеливания
- измерение времени выполнения программы
- тестирование производительности при различном количестве потоков

## Требования

- компилятор с поддержкой OpenMP (g++, clang)
- Linux / Unix система
- CMake

## Компиляция и запуск

```bash
# Создаем папку сборки
mkdir build
cd build

# Генерируем Makefile
cmake ..

# Компилируем программу
make
```

## Запуск программы

```bash
./bin/integral_omp
```
