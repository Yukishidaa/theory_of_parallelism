# Параллельное умножение матрицы на вектор

## Описание
Программа реализует параллельное умножение матрицы на вектор с использованием OpenMP. 

## Функциональность
- Параллельная инициализация матрицы и вектора
- Параллельное умножение матрицы на вектор
- Замер времени выполнения
- Тестирование для различных размеров матриц и количества потоков

## Требования
- Компилятор с поддержкой OpenMP (g++, clang)
- Операционная система Linux/Unix
- Python 3 с библиотеками matplotlib (для построения графиков)

## Компиляция и запуск
``` bash
# Создаем папку для сборки
mkdir build
cd build

# Конфигурируем проект
cmake ..

# Собираем
make

# Запуск программы
./bin/matrix_vector

# Построение графика
python3 plot_speedup.py
